## 2. 데모 데이터셋 (2026-challenge-demos)

### 2.1 규모

- 페이지 원문: "20,000 human-collected teleoperation demos across 100 tasks and is 3.27 TB in total. It follows the LeRobot V3 format with customizations for better data handling." (원문의 LeRobot 은 링크)
- 과제당 200개 시연. 30 fps. 총 210,916,774 프레임(`info.json` / 카드).
- 평균 길이: 페이지 표 "351.54 seconds / 5.9 minutes". index.html 은 "20,000 human teleoperation demos, 1,950 hours in total".
- 로봇: `robot_type: R1Pro`. 수집 도구 JoyLo(양손 조종기 + 소형 로봇팔로 전신을 원격조작).

### 2.2 폴더 구조

| 폴더 | 원문 설명 | 실제 파일 (HF API 기준) |
|---|---|---|
| `annotations` | "Language annotations for each episode." | `task-NNNN/episode_XXXXXXXX.json` 20,000개 + `skill_summary.csv`, `skill_type_summary.csv` |
| `data` | "Low-dimensional data, including proprioceptions, actions, camera poses, and related episode data." | `chunk-NNN/file-NNN.parquet` 955개 (74.6 GB) |
| `meta` | "Metadata folder containing episode-level information." | `info.json`, `stats.json`, `tasks.jsonl`, `tasks.parquet`, `episodes/chunk-NNN/*.parquet` |
| `videos` | "Visual observations, including RGB and depth." | 카메라·모달리티별 `chunk-NNN/file-NNN.mp4` |

영상 용량(HF 파일 크기 합계, 계산값): 헤드 RGB 570 GB, 손목 RGB 216 GB × 2, 헤드 깊이 1,450 GB, 손목 깊이 369·359 GB. → **RGB 만 받으면 약 1.0 TB, 헤드 RGB 만이면 약 0.57 TB**, 깊이가 전체의 2/3.

### 2.3 특징(feature) — `meta/info.json`

| 키 | 형태 | 내용 |
|---|---|---|
| `observation.state` | float32 [61] | proprio. 순서는 아래 2.4 |
| `action` | float32 [23] | 행동. 순서는 아래 2.5 |
| `observation.rgb.zed_link_camera_0` | 영상 720×720×3 | 헤드 카메라 RGB |
| `observation.rgb.left_realsense_link_camera_0`, `...right...` | 영상 480×480×3 | 손목 카메라 RGB |
| `observation.depth_linear.<카메라>` | 영상 H×W×1 | 깊이 |
| `observation.robot2cam_pose.<카메라>` | float32 [7] | 로봇 기준 카메라 pose (위치3 + 쿼터니언4) |
| `next.reward`, `next.terminated`, `next.truncated` | | |
| `timestamp`, `frame_index`, `episode_index`, `index`, `task_index` | | |

- 영상 코덱: RGB 는 HEVC(yuv420p), 깊이는 HEVC `gray12le`. 디코딩에 HEVC 지원 ffmpeg/pyav 가 필요.
- 깊이 인코딩: 페이지 원문 "Depth videos are log-quantized during replay and dequantized back to metric depth values.", 범위 "[0, 10] meters". `info.json` 에는 `video.depth_min 0.01`, `video.depth_max 10.0`, `video.use_log true`, `depth_unit` = mm, `video.output_unit` = mm 가 적혀 있다 → **로더가 내놓는 단위가 mm 일 수 있다.** 평가 때 OmniGibson 의 `depth_linear` 는 미터로 보인다(추정) → 학습·평가 단위를 맞출 것.
- RGB 모양 원문: "`(height, width, 4)`" — 페이지는 4채널로 적었다(시뮬레이터 관측은 RGBA). 데모 영상 파일은 3채널.

### 2.6 주석(annotations)

- 에피소드마다 JSON 1개. 최상위 키: `task_name`, `meta_data`(`task_duration`, `valid_duration`), `skill_annotation`, `primitive_annotation` (로컬 `annotations\task-0000\episode_00000010.json` 확인).
- `skill_annotation` 항목: `skill_description`(예: "move to"), `object_id`, `manipulating_object_id`, `frame_duration`(시작·끝 프레임), `skill_type`, `memory_prefix`, `spatial_prefix` 등.
- 07/27 공지 원문: "Added `meta/tasks.jsonl` with natural-language task descriptions for all 100 challenge tasks." / "Uploaded per-episode language annotations for all 20,000 demonstrations."
- `meta/episodes` parquet 에는 `task_instance_id`, `raw_episode_id`, `annotation_path`, `demo_index_within_task` 열이 있어 원본 HDF5·주석과 연결할 수 있다.

### 2.7 페이지 통계와 실제 주석이 다르다

- 페이지 표(Dataset Statistics): Total Skills = 270,600, Unique Skills = 31, Avg. Skills per Trajectory = 27.06. 이 세 값은 2025 데이터 페이지 값과 똑같다([raw/site_challenge_archive_2025_dataset.md](../../raw/site_challenge_archive_2025_dataset.md)). 270,600 ÷ 20,000 = 13.53 이라 27.06 과도 맞지 않는다 → 2025 값을 그대로 둔 것으로 보인다.
- 실제 `annotations/skill_summary.csv`: 스킬 종류 **35개**, 스킬 구간 합계 **406,341개** → 에피소드당 약 20.3개(계산값). 많은 순: move to 143,566 / pick up from 93,092 / place in 43,743 / place on 34,580.
- `skill_type_summary.csv`: navigation 139,556 / uncoordinated 230,674 / coordinated 36,111 (양손 협응이 필요한 구간은 약 9%).

### 2.8 받는 방법 (과제 단위로)

전체가 3.27 TB 라 과제별 chunk 만 받는다. baselines.html 원문 명령:

```bash
export TASK_ID=0    # 0-indexed task id; maps to chunk-000, chunk-001, ...
CHUNK=$(printf "chunk-%03d" $TASK_ID)

huggingface-cli download behavior-1k/2026-challenge-demos \
    --repo-type dataset \
    --local-dir "$DATA_ROOT" \
    --include "data/$CHUNK/**" \
    --include "meta/episodes/$CHUNK/**" \
    --include "videos/*/$CHUNK/**" \
    --include "meta/info.json" \
    --include "meta/stats.json" \
    --include "meta/tasks.parquet"
```

- 주석은 경로가 `annotations/task-NNNN/` 로 다르다(4자리). `annotations/*.*` 같은 넓은 패턴은 요청이 폭증해 HF 요청 한도(429)에 걸린 적이 있다 → [설치기록.md](설치기록.md) 막힌 점 8.
- 카메라·모달리티를 골라 받으려면 `--include videos/observation.rgb.zed_link_camera_0/$CHUNK/**` 처럼 좁힌다(깊이 제외 시 용량 1/3).
- 데모 카드의 로딩 예시 원문(LeRobot): `LeRobotDataset("behavior-1k/2026-challenge-demos", episodes=[0], download_videos=False)`, `revision="v3.0"`.
- 과제 하나 크기는 과제 길이에 비례한다. 0번(turning_on_radio, 가장 짧음)은 메타 포함 약 5.2 GB 였다([설치기록.md](설치기록.md)). 평균은 약 33 GB(3.27 TB ÷ 100, 계산값).

## 3. 원본 HDF5 (2026-challenge-rawdata)

- 페이지 원문: "2026-challenge-rawdata contains the original raw HDF5 data for the 20k teleoperation demos and is 1.44 TB in total. These files contain everything needed to replay exact trajectories in OmniGibson."
- 파일: `task-NNNN/episode_XXXXXXXX.hdf5` 20,000개.
- 재생 스크립트: `OmniGibson/scripts/learning/replay_obs.py` (페이지 원문 경로). 학습 때는 특권 정보 사용이 허용되므로, 재생으로 물체 pose·분할·점군 등 추가 관측을 뽑아 보조 학습 신호로 쓸 수 있다([평가규칙_원문.md](평가규칙_원문.md) 2절).
- 2025 데모에는 분할(seg_instance_id) 영상이 들어 있었지만 2026 데모에는 RGB·깊이만 있다 → 분할이 필요하면 재생해서 만든다.

- 과제 인스턴스 폴더(로컬 확인)
  - `metadata\B100_task_misc.csv` — 과제 id·이름·평가 때 불러올 방 목록
  - `metadata\task.jsonl` — 과제별 사람 통계(`length`, `distance_traveled`, `left/right_eef_displacement`, `num_episodes`=200). 제한시간·효율 지표 정규화에 쓰임
  - `metadata\available_tasks.yaml` — 과제별 장면·로봇 시작 위치
  - `scene_test\public\<장면>\json\` — 공개 평가 인스턴스(과제당 20개, id 301~320) 2,200개 파일
  - `scenes\<장면>\json\` — 학습용 인스턴스
  - `README.md` — 원격조작자용 지침(요약: 탐색 동작 금지, 헛잡기·실패한 잡기는 허용하지 않고 체크포인트로 되돌려 다시 녹화) → 시연에 탐색·실패 복구 동작이 거의 없는 이유. 2025 1위 보고서도 복구 데이터가 없는 것을 큰 약점으로 꼽았다([2025대회_분석.md](2025대회_분석.md)).

## 5. 2025 데이터와 비교

| | 2025 | 2026 |
|---|---|---|
| 과제 / 시연 | 50 / 10,000 | 100 / 20,000 |
| 크기 | 페이지 표기 "~1.5T" (HF 저장 용량은 약 2.07 TB) | 3.27 TB |
| 시각 모달리티 | RGB, 깊이, 인스턴스 분할(seg_instance_id) | RGB, 깊이 |
| 평균 길이 | 397.04초 | 351.54초 |
| LeRobot 판 | v2.1 (카드의 `codebase_version`) | v3.0 |

- 2026 의 0~49번 과제 시연 평균 길이(397초, `task.jsonl` 계산)가 2025 평균 397.04초와 거의 같다 → 앞 50개 과제의 시연은 2025 것을 다시 쓴 것으로 보인다(추정, 공식 확인 없음).

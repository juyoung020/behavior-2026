### 2.4 실행 명령 (README 원문 코드 블록)

```bash
git clone --recurse-submodules https://github.com/ilialarchenko/behavior-1k-solution.git
bash setup_remote.sh
uv run scripts/compute_norm_stats.py --config-name pi_behavior_b1k_fast --correlation
uv run scripts/train_fast_tokenizer.py --config-name pi_behavior_b1k_fast --encoded-dims="0:6,7:23" --vocab-size=1024
uv run scripts/train.py pi_behavior_b1k_fast --batch_size=2048 --num_train_steps=200000 --fsdp_devices=8 --save_interval=250 --keep_period=4000 --log_interval=25
uv run scripts/serve_b1k.py --task-checkpoint-mapping task_checkpoint_mapping.json policy:checkpoint --policy.config pi_behavior_b1k_fast --policy.dir ~/models/checkpoint_1
python BEHAVIOR-1K/omnigibson/learning/eval.py log_path=./eval_logs policy=websocket task.name=make_microwave_popcorn model.host=localhost eval_instance_ids="[0,1,2,3]"
```

- 마지막 줄은 **2025 평가기** 명령(hydra 형식, `omnigibson/learning/eval.py`). 2026 은 `python -m omnigibson.eval.eval --task-name ...` ([평가기_사용법.md](평가기_사용법.md)).
- README 원문: "We used Fully Sharded Data Parallel (FSDP) - for training that allows to use a bigger batch size on multiple GPUs." / "`--resume` works only with the same number of GPUs as the original training."
- README 원문: "this repo supports only our modification of the model developed for the competition" — 일반 π0.5 는 원래 openpi 를 쓰라는 뜻.
- 학습 스텝: README 기본값은 200,000 이지만 저자 답변(이슈 #16) 원문 "200 000 steps is just a default config. The original 50 tasks model was trained for ~50k steps only, that corresponds to approximately one epoch." — https://github.com/IliaLarchenko/behavior-1k-solution/issues/16

### 2.5 환경 · GPU

- `setup_remote.sh`: Python 3.11(`PYTHON_VERSION` 기본값), CUDA 12.4(`CUDA_VERSION` 기본값), uv, apt 로 GL/GLFW/ffmpeg 등. BEHAVIOR-1K 는 서브모듈에서 `uv pip install -e bddl`, `uv pip install -e OmniGibson[eval]` — 즉 **정책 서버 가상환경에 2025 시절 OmniGibson 이 같이 설치된다**.
- `pyproject.toml`: `requires-python = ">=3.11,<3.12"`, `jax[cuda12]>=0.4.35`, `torch>=2.5.1`, `lerobot>=0.3.0`, openpi 는 서브모듈 경로 편집 설치.
- 추론 메모리: `serve_b1k.py` 원문 "os.environ.setdefault('XLA_PYTHON_CLIENT_MEM_FRACTION', '0.5')  # Use 50% of GPU memory". `policy_config.py` 원문 주석 "# JAX model loading - load directly as bfloat16 to save memory (12GB vs 24GB)". 체크포인트 교체기 원문 "Only one checkpoint in memory at a time." — 4개를 동시에 올리지 않는다. README 에 추론 GPU 최소 사양 표는 없다.
- 재현자 기록: RTX 4090 24GB 8장(이슈 #10), RTX PRO 6000 Blackwell 96GB 2장(KunHsiang 포크). 16 GB 한 장으로 서버+시뮬레이터를 같이 돌린 공개 기록은 못 찾음. 2위 재현자 수치(3.5절: 서버 약 9 GB + Isaac Sim 약 8 GB)를 보면 16 GB 한 장은 빠듯하다(추정).

## 5. 2026 에 바로 쓸 수 있는 것

1. **1위 가중치로 과제 0~49 채우기** — 가장 빠른 길. `refs\behavior-1k-solution_alstar8` 의 서버(`scripts/serve_b1k.py` + `--convert-2025-actions` + 설정 `pi_behavior_2025_submission`)가 2026 평가기(`omnigibson.eval`)와 61차원 proprio, 배치 차원, 모델 쪽 2025 단계 수 표를 이미 처리한다. 남은 일 두 가지: (a) 래퍼의 단계 투표 상한을 2025 표로(2.9절 #6, 17과제), (b) base_qvel 좌표계(2.9절 #3) — wjmsxbd 문서의 `absolute` 옵션처럼 서버에서 옛 좌표계로 돌려 넣을지 실험.
2. **Blackwell 주의** — 1위 저장소가 고정한 BEHAVIOR-1K(Isaac Sim 4.5)로는 이 PC 에서 평가하지 말 것(공식 답변: 4.5 트랙은 Blackwell 미지원). 평가는 로컬 v3.9.3(Isaac Sim 5.1)로, 서버만 1위 코드로. 리눅스에서 시뮬레이터를 돌릴 땐 드라이버 595.84 세그폴트 기록(bushuyeu) 참고.
3. **2위 공개 pt50 은 기대치를 낮출 것** — 제3자 재현 0/40(라디오), 50과제 Q 약 0.03(이슈 #24). 제출본이 아니다. 대신 `delinqu/comet-1.5k`(103.6 GB, MIT) RFT 데이터는 1위 구조 재학습에 섞여 쓰이고 있다(alstar8: 2026 데모 60% + Comet RFT 40%).
4. **3위 교훈** — 15과제만 제출해도 3위였다. 과제를 좁게 잡아 확실히 푸는 전략도 순위에 통한다. 다만 2026 은 100과제 평균이므로 1위처럼 폭넓게 부분점수를 따는 쪽과 저울질해야 한다([2025대회_분석.md](2025대회_분석.md) 6절 1번과 함께 볼 것).
5. **평가 가속 참고** — wjmsxbd 의 GPU 한 장당 환경 2개·배치 2 추론 구조(`refs\2026-challenge-evaluation_wjmsxbd\docs\pi05_behavior_2026_eval_acceleration.md`)는 1,000 에피소드 평가 시간을 줄이는 데 참고할 만하다. 단 16 GB 한 장에선 서버(약 9 GB)+시뮬레이터(약 8~10 GB) 조합이 이미 빠듯하다(3.8절 수치, 추정).
6. **체크포인트** — 받으려면 1.2절의 안 A~D 중 하나를 고르면 된다. 1번 목적이면 안 A(63 GB)로 충분하다.

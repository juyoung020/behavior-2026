## 1. 리더보드가 어떻게 만들어지나

- Space README 원문: "Evaluation is run manually by the challenge organizers on the official OmniGibson setup. Public submission metadata and verified results are stored in the `data/` directory in this repository."
- 원문: "Portal responses are written as JSON files to the private Hugging Face dataset configured by `SUBMISSION_DATASET_REPO`." (기본값 `behavior-1k/challenge-submissions`, 비공개)
- 원문: "Scores are averaged over all 100 challenge tasks, with unsubmitted tasks contributing zero."
- 집계 방식(스크립트 요약): 제출의 "Self-evaluation results URL" 에서 JSON 을 모아 과제별 q_score 평균 → 합 ÷ 100. 완전성공률도 같은 방식. → 과제 몇 개만 낸 팀은 점수가 낮게 보인다.
- 표의 순위 칸(Rank)은 검증 전이라 비어 있고, 제출 시각 역순으로 나열된다.
- 앱 코드의 제외 목록: `IGNORED_SUBMISSION_IDS = {"20260924T054531Z-test-test"}`(시험 제출).

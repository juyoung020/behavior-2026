# 실행 기록 — π0.5 기본 체크포인트로 turning_on_radio 돌리기 (2026-09-29)

공식 베이스라인(π0.5, radio 전용 체크포인트)을 이 PC 에서 처음부터 끝까지 돌려 본 기록.
명령은 `C:\behavior-2026\tools\`, 결과는 `C:\behavior-2026\outputs\`, 로그는 `C:\behavior-2026\logs\`.

## 1. 실행 방법

```
# 1) 정책 서버 (WSL)
wsl -d Ubuntu-22.04 -u juyoung -- bash /mnt/c/behavior-2026/tools/run_pi05_server.sh        # 과제 기본 turning_on_radio
# 2) 평가기 (Windows, 새 창)
powershell -ExecutionPolicy Bypass -File C:\behavior-2026\tools\run_eval_radio.ps1          # 공식 기본 제한시간
powershell -ExecutionPolicy Bypass -File C:\behavior-2026\tools\run_eval_radio.ps1 -Gui     # 시뮬레이터 뷰어 창
powershell -ExecutionPolicy Bypass -File C:\behavior-2026\tools\run_eval_radio.ps1 -MaxSteps 500   # 짧은 시험
```

- 서버: openpi `scripts/b1k/serve_b1k.py`, `--policy.config pi05_b1k`, `--repo-id turning_on_radio`
  (체크포인트 안 정규화 통계 폴더 `assets/turning_on_radio` 이름과 맞춤), receding horizon 16.
- 공식 명령과 다른 점: GPU 1장(16 GB)을 시뮬레이터와 나눠 써서 `XLA_PYTHON_CLIENT_MEM_FRACTION` 을 0.85 → 0.5.
- 평가기: `python -m omnigibson.eval.eval --task-name turning_on_radio --mode public_test --instance-indices 0 --write-video`
  (+ 아래 고친 점 두 가지). 공식 결과를 낼 때는 `--max-steps` 를 주지 않는다(기본 = 사람 평균 × 1.5).

## 2. 돌리려고 고친 것 (두 레포는 수정하지 않음)

| 증상 | 원인 | 조치 |
|---|---|---|

Intel 은 "may cause crashes or silently produce incorrect results" 라고 경고) |
| 첫 행동 요청에서 서버 오류 1011, 서버 로그 `KeyError: 'robot::proprio'` | openpi(behavior 브랜치, 2026-06-28) 의 R1Pro 이름은 `robot`, 현재 평가기 설정 `r1pro.yaml` 은 `robot_r1` | `src\configs\r1pro_openpi.yaml` = 공식 `r1pro.yaml` 사본에서 `name` 과 카메라 센서 이름 3개(`robot_r1:` → `robot:`)만 바꿔 `--robot-config` 로 사용. 공식 파일과 다른 줄은 4줄뿐 |

## 5. 뷰어 화면 읽는 법

- 왼쪽 Viewport 1·2·3 = 로봇 카메라 3대(설정 순서상 왼손목·오른손목·머리) — π0.5 입력으로 들어가는 영상(224×224 로 줄여서).
- 가운데 큰 Viewport(`viewer_camera`) = 사람이 보는 자유 시점 카메라. 정책 입력 아님.
  보기: 마우스 오른쪽 버튼 + W/A/S/D, 또는 Stage 에서 로봇 선택 후 F.
- 오른쪽 Stage(장면 물체 목록)·Property, 아래 Content(에셋 브라우저)는 편집 도구.

## 6. 점수 계산 (코드 확인: `omnigibson/metrics/task_metric.py`, `eval/utils/score_utils.py`)

- 판마다: 완전 성공이면 1.0, 아니면 **시작 때 만족 안 됐던 목표 조건 중 끝에 만족한 비율**(목표 선택지가 여럿이면 최댓값).
- 과제별 평균 → 100 과제 평균이 순위 점수 Q. 안 낸 판은 0.
- 동점일 때만: 시간 = 사람 평균 스텝 ÷ 로봇 스텝(채점 시 `3 − 2 / 이 값`), 몸체 이동·양손 이동 = 사람 평균 ÷ 로봇.

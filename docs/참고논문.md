OmniGibson 시뮬레이터는 따로 된 arXiv 논문 없이 BEHAVIOR-1K 논문 안에서 소개된다(초록 원문: "The second is OMNIGIBSON, a novel simulation environment that supports these activities via realistic physics simulation and rendering of rigid bodies, deformable bodies, and liquids."). 사이트 FAQ 에 OmniGibson 과 BEHAVIOR-1K 관계 설명 → [raw/site_other_faq.md](raw/site_other_faq.md).

## 1. BEHAVIOR-1K (Li et al., 2024)

- 두 부분: 일상 활동 1,000개 정의(장면 50개, 물체 9,000개 이상) + 시뮬레이터 OmniGibson(강체·변형체·액체).
- 원문: "Our experiments indicate that the activities in BEHAVIOR-1K are long-horizon and dependent on complex manipulation skills, both of which remain a challenge for even state-of-the-art robot learning solutions."
- 대회 100과제는 이 1,000개 중에서 고른 것. 과제 정의는 BDDL 로 되어 있다.

## 2. BEHAVIOR (Srivastava et al., 2021)

- 원조 벤치마크(활동 100개). BDDL 을 처음 제안: 원문 "we propose an object-centric, predicate logic-based description language for expressing an activity's initial and goal conditions, enabling generation of diverse instances for any activity."
- 점수 체계의 뿌리: 원문 "we introduce a set of metrics to measure task progress and efficiency, absolute and relative to human demonstrators." → 대회의 q_score(부분 성공)와 사람 대비 효율 지표(시간·이동거리)가 여기서 왔다.

## 3. BEHAVIOR Robot Suite (Jiang et al., 2025)

- 가정 작업에 필요한 세 능력: 원문 "bimanual coordination, stable and precise navigation, and extensive end-effector reachability."
- 원문: "Built on a bimanual, wheeled robot with a 4-DoF torso, BRS integrates a cost-effective whole-body teleoperation interface for data collection and a novel algorithm for learning whole-body visuomotor policies." → 대회 로봇 R1Pro(바퀴 달린 양팔 로봇, 몸통 4관절)와 JoyLo 원격조작이 여기서 나왔다. 2025 참가 공고도 이 논문을 로봇 선택 근거로 든다.

## 4. π0 / π0.5 (Physical Intelligence)

- π0: VLM 에 행동 전문가를 붙여 flow matching 으로 연속 행동 묶음을 생성하는 VLA.
- π0.5: 원문 "a new model based on $π_{0}$ that uses co-training on heterogeneous tasks to enable broad generalization." 여러 로봇 데이터·웹 데이터·고수준 의미 예측(하위과제 예측)을 함께 학습.
- 원문: "we demonstrate for the first time that an end-to-end learning-enabled robotic system can perform long-horizon and dexterous manipulation skills, such as cleaning a kitchen or bedroom, in entirely new homes." → 긴 가정 작업이라는 점에서 대회와 잘 맞아 2025 1·2위가 모두 π0.5 를 택했다.
- 대회 포크: `wensi-ai/openpi` behavior 브랜치 → [베이스라인.md](베이스라인.md).

## 5. GR00T N1 (NVIDIA, 2025)

- 원문: "GR00T N1 is a Vision-Language-Action (VLA) model with a dual-system architecture. The vision-language module (System 2) interprets the environment through vision and language instructions. The subsequent diffusion transformer module (System 1) generates fluid motor actions in real time."
- 대회 베이스라인은 후속판 N1.7(`nvidia/GR00T-N1.7-3B`, 백본 Cosmos-Reason2-2B). N1.7 별도 논문은 이번 조사에서 확인하지 않았다.

## 6. 2025 대회 보고서 두 편

자세한 내용은 [2025대회_분석.md](2025대회_분석.md).

- 1위(Larchenko et al.): 원문 "Our primary contribution is correlated noise for flow matching, which improves training efficiency and enables correlation-aware inpainting for smooth action sequences." / "Our approach achieves 26% q-score across all 50 tasks on both public and private leaderboards."
- 2위(Team Comet, NVIDIA): π0.5 사전학습 범위 확대 + RFT 후학습, 소거 실험(실행 방식·horizon·입력·해상도·행동 표현). 대회 뒤 공개 인스턴스 Q 0.345.

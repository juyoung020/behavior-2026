## 1. 한 줄 요약

시뮬레이터 OmniGibson(NVIDIA Isaac Sim 5.1 기반) 속 집에서, 바퀴 달린 양팔 로봇 R1Pro 가 집안일 100가지를 해내도록 정책(policy, 관측→행동 모델)을 만들어 낸다. 평가 때 쓸 수 있는 입력은 로봇 카메라의 RGB·깊이와 로봇 자기 상태(proprioception)뿐.

원문: "Join us for the second year of the BEHAVIOR Challenge: solve 100 full-length household tasks in the realistic BEHAVIOR-1K environment."

## 4. 한눈에 (index.html "Challenge at a Glance" 원문)

| 항목 | 원문 |
|---|---|
| Tasks | "100 full-length household tasks" |
| Environments | "7 scenes, including 4 new scenes" |
| Evaluation track | "One track using RGB + depth + proprioception" |
| Demonstrations | "20,000 human teleoperation demos, 1,950 hours in total" |
| Baselines | "π0.5 (pi0.5) and GR00T N1.7" |
| Ranking metric | "Average task success score with BDDL partial credit" |

- 과제: 2025 과제 50개 + 새 과제 50개 → [과제목록.md](과제목록.md)
- 로봇: 기본 R1Pro(바퀴 이동 + 몸통 4관절 + 7관절 팔 2개 + 그리퍼 2개, 행동 23차원). 다른 OmniGibson 로봇도 허용.
- 점수: 과제마다 목표 조건(BDDL predicate) 중 새로 만족시킨 비율 = q_score, 100과제 평균. 완전 성공 못 해도 부분 점수 → [평가규칙_원문.md](평가규칙_원문.md)
- 평가: 과제마다 공개 인스턴스 10개 × 1회 = 1,000 롤아웃을 **직접 돌려서** 결과 JSON·영상을 제출. 마감 뒤 상위 5팀만 주최측이 비공개 인스턴스로 다시 평가.

## 8. 이번 조사에서 확인된 주의점 (자세한 내용은 각 문서)

1. `v3.9.3` 태그가 GitHub 에 없다(`v3.9.3-post1` 만 있음). 공지는 v3.9.2, 규칙 페이지는 v3.9.3 → [FAQ_공지.md](FAQ_공지.md)

3. 행동 묶음 재생의 예약 필드는 실제로 `__action_chunk_size__`(웹페이지에는 `action_chunk_size` 로 보임) → [평가기_사용법.md](평가기_사용법.md) 5.3
4. 포털은 **팀의 마지막 유효 제출**을 공식 순위에 쓴다 → [제출지침.md](제출지침.md)
